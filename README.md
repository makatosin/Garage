# Garage

App web per tenere il conto di rifornimenti, consumi, spese, manutenzioni e viaggi delle proprie auto.
Si apre dal browser e si installa sull'iPhone con "Aggiungi alla schermata Home"; funziona anche offline.

- **Statistiche**: consumo (l/100 km e km/l), grafico di prezzo e consumi, costi al giorno e ogni 100 km, stime mensili e annuali.
- **Carburante**: pieni e parziali, calcolo automatico di litri / €/l / totale.
- **Spese**: categorie e promemoria ogni N mesi o N km.
- **Viaggi**: intervalli di date e km con report dei costi.
- **Altro**: più veicoli, export/import CSV, backup completo.

I dati restano solo sul dispositivo (localStorage): esporta ogni tanto un backup.
